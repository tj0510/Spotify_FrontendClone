# 🎵 Spotify Frontend Clone

A responsive frontend clone of the Spotify web player designed using **HTML** and **CSS**. This project replicates the look and feel of Spotify’s UI, including navigation, library cards, a music player section, and featured charts — ideal for sharpening UI development skills.

## 🚀 Features

- 🎧 Sidebar with navigation and library options  
- 🔍 Search and explore music/playlists  
- 📃 Cards section with Recently Played, Trending, and Charts  
- 🎛️ Fixed music player at the bottom  
- 📱 Responsive design with media queries  
- 💡 Interactive hover and button effects
- Clean, Spotify-inspired aesthetics

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **Font Awesome** (icons)
- **Google Fonts** (Montserrat)
